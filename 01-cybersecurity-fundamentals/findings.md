# Learning Findings

## 1. Confidentiality

Confidentiality means protecting information from unauthorized access.

During my study, I learned that sensitive information should only be available to authorized users.

Common security controls include:

- Passwords
- Authentication
- Access control
- Encryption
- Multi-factor authentication

### Security Observation

If an unauthorized person can access sensitive information, confidentiality has been compromised.

---

## 2. Integrity

Integrity means protecting information from unauthorized modification.

Data should remain accurate, complete, and trustworthy.

Common controls include:

- Hashing
- Digital signatures
- File permissions
- Access control
- Logging

### Security Observation

If an attacker changes important information without authorization, the integrity of that information is compromised.

---

## 3. Availability

Availability means ensuring that authorized users can access systems and information when required.

Availability can be affected by:

- Denial of Service attacks
- DDoS attacks
- Hardware failures
- Network failures
- Ransomware
- Power failures

Common security controls include:

- Backups
- Redundant systems
- Monitoring
- Disaster recovery
- Load balancing

### Security Observation

A system can be secure from unauthorized access but still have a security problem if legitimate users cannot access the service.

---

## 4. Common Cyber Threats

I studied several common cybersecurity threats.

### Malware

Malware is malicious software designed to damage systems, steal information, or provide unauthorized access.

Examples:

- Virus
- Worm
- Trojan
- Ransomware
- Spyware
- Rootkit
- Keylogger

### Phishing

Phishing attempts to trick users into providing sensitive information such as usernames, passwords, or financial information.

### Social Engineering

Social engineering targets people by manipulating them into revealing information or performing an action.

Examples:

- Phishing
- Vishing
- Smishing
- Pretexting
- Baiting

### Brute Force

A brute force attack attempts to discover credentials by trying multiple possible combinations.

### Insider Threat

An insider threat can occur when someone with legitimate access intentionally or accidentally causes a security problem.

---

## 5. Authentication and Authorization

I learned the difference between authentication and authorization.

### Authentication

Authentication verifies the identity of a user.

Question:

"Who are you?"

Examples:

- Password
- Fingerprint
- One-time password
- Security key

### Authorization

Authorization determines what an authenticated user is allowed to access or perform.

Question:

"What are you allowed to do?"

### Security Observation

Authentication and authorization are different security processes.

A user may successfully authenticate but still not have permission to access a particular resource.

---

## 6. Least Privilege

The principle of least privilege means users should receive only the permissions required to perform their tasks.

For example, a user who only needs to read a file should not automatically receive permission to delete it.

### Security Observation

Reducing unnecessary permissions can reduce the potential impact of compromised accounts.

---

## 7. Defense in Depth

Defense in depth means using multiple layers of security.

Example:

Firewall
↓
Authentication
↓
Access Control
↓
Endpoint Security
↓
Monitoring
↓
Backup

### Security Observation

If one security control fails, additional security layers may still provide protection.

---

## 8. Offensive Security

Offensive security focuses on identifying and testing security weaknesses.

Examples:

- Penetration Testing
- Ethical Hacking
- Red Teaming
- Vulnerability Assessment

The goal of authorized security testing is to identify weaknesses so they can be fixed.

---

## 9. Defensive Security

Defensive security focuses on protecting systems and detecting and responding to security incidents.

Examples:

- Security Operations Center
- Security Monitoring
- Threat Detection
- Incident Response
- Digital Forensics
