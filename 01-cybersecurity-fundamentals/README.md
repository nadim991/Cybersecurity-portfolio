# Cybersecurity Fundamentals

## Overview

This project covers the fundamental concepts of cybersecurity.

## Topics Covered

- What is Cybersecurity
- CIA Triad
- Confidentiality
- Integrity
- Availability
- Malware
- Phishing
- Social Engineering
- DoS and DDoS
- Man-in-the-Middle Attack
- Brute Force Attack
- Insider Threats
- Offensive Security
- Defensive Security
- Security Principles

## Learning Objectives

- Understand the fundamentals of cybersecurity
- Understand the CIA Triad
- Understand common cyber threats
- Understand basic security principles
- Understand offensive and defensive security

## Conclusion

This project helped me build a foundation in cybersecurity and prepare for more advanced areas such as reconnaissance, vulnerability assessment, penetration testing, and digital forensics.
