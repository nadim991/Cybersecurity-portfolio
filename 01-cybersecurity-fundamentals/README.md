# Cybersecurity Fundamentals

A beginner-friendly study and practical documentation project covering the fundamental concepts of cybersecurity.

## Overview

Cybersecurity is the practice of protecting computers, networks, applications, systems, and data from unauthorized access, attacks, damage, and disruption.

This project documents my learning of the core concepts that form the foundation of cybersecurity.

## Topics Covered

### 1. What is Cybersecurity?

Cybersecurity focuses on protecting digital systems, networks, applications, and information from cyber threats.

### 2. CIA Triad

The CIA Triad is one of the fundamental concepts of cybersecurity.

It consists of:

- Confidentiality
- Integrity
- Availability

#### Confidentiality

Ensures that information is accessible only to authorized users.

Examples:

- Passwords
- Access control
- Encryption
- Multi-factor authentication

#### Integrity

Ensures that information remains accurate and is not modified without authorization.

Examples:

- Hashing
- Digital signatures
- File permissions
- Access controls

#### Availability

Ensures that systems and information remain accessible when authorized users need them.

Examples:

- Backups
- Redundant systems
- Load balancing
- Disaster recovery

## 3. Common Cybersecurity Threats

### Malware

Malware is malicious software designed to damage systems, steal information, or provide unauthorized access.

Examples:

- Virus
- Worm
- Trojan
- Ransomware
- Spyware
- Rootkit
- Keylogger

### Phishing

Phishing is a social engineering technique where attackers attempt to trick users into providing sensitive information.

### Social Engineering

Social engineering involves manipulating people into revealing information or performing actions that may compromise security.

Examples:

- Phishing
- Vishing
- Smishing
- Pretexting
- Baiting

### DoS and DDoS

Denial of Service attacks attempt to make a service unavailable to legitimate users.

DDoS attacks use multiple systems to generate traffic toward a target.

### Man-in-the-Middle Attack

A Man-in-the-Middle attack occurs when an attacker attempts to intercept communication between two parties.

Example:

User → Attacker → Server

### Brute Force Attack

A brute force attack attempts to discover credentials by trying many possible combinations.

### Insider Threat

An insider threat involves a person with legitimate access who intentionally or accidentally causes a security problem.

## 4. Basic Security Principles

### Least Privilege

Users should receive only the permissions required to perform their tasks.

### Defense in Depth

Organizations should use multiple layers of security so that one failed security control does not expose the entire system.

### Secure by Design

Security should be considered during the design and development of systems and applications.

## 5. Authentication vs Authorization

### Authentication

Authentication verifies the identity of a user.

Example:

"Who are you?"

### Authorization

Authorization determines what an authenticated user is allowed to access or do.

Example:

"What are you allowed to do?"

## 6. Offensive Security

Offensive security focuses on identifying and testing security weaknesses.

Examples:

- Penetration Testing
- Ethical Hacking
- Red Teaming
- Vulnerability Assessment

## 7. Defensive Security

Defensive security focuses on detecting, preventing, and responding to attacks.

Examples:

- Security Operations Center (SOC)
- Incident Response
- Threat Detection
- Security Monitoring
- Digital Forensics
