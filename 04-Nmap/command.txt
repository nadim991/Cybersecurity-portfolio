Nmap Network Scanning Lab

Target:
192.168.196.129

1. Host Discovery
nmap -sn 192.168.196.129

2. Basic Port Scan
nmap 192.168.196.129

3. SYN Scan
sudo nmap -sS 192.168.196.129

4. Service Version Detection
sudo nmap -sV 192.168.196.129

5. OS Detection
sudo nmap -O 192.168.196.129

6. Combined Scan
sudo nmap -sS -sV -O 192.168.196.129
